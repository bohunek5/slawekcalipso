Calipso 2027 architectural illustrations

Source: the photo-led Three.js reconstruction in src/boat.js and src/details.js.
Reproduction: run npm run dev, then node qa/render-studio.mjs.
Rendering: orthographic Three.js views, local procedural studio illumination, WebP 2800px wide.
Profile / plan drawings are illustrative. Published hull dimensions come from manufacturer documents listed in SOURCES.md.
These assets are not photographs, original CAD files, construction drawings or proof of factory equipment.
No generative image editing or replacement yacht geometry was used.
